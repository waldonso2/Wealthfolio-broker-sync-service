So importierst du es
  • Windows (Chrome, Edge): Datei öffnen → Zertifikat installieren → Aktueller Benutzer → Alle Zertifikate in folgendem Speicher speichern → Vertrauenswürdige Stammzertifizierungsstellen – nicht „automatisch auswählen“, sonst landet es unter den Zwischenzertifizierungsstellen und wirkt nicht. Prüfen lässt es sich mit certmgr.msc.
  • macOS (Safari, Chrome): Datei öffnen (Schlüsselbundverwaltung) → Zertifikat doppelklicken → Vertrauen → Immer vertrauen.
  • Firefox: Einstellungen → Datenschutz & Sicherheit → Zertifikate anzeigen → Zertifizierungsstellen → Importieren → „Dieser CA vertrauen, um Websites zu identifizieren“.
  • iPhone/iPad: Datei in Safari laden → Einstellungen → Profil geladen → Installieren, danach Allgemein → Info → Zertifikatsvertrauenseinstellungen einschalten.
  • Android: Einstellungen → Sicherheit → Verschlüsselung & Anmeldedaten → Zertifikat installieren → CA-Zertifikat.

Danach den Browser ganz beenden und neu starten (Chrome/Edge: chrome://restart; Android: App „Beenden erzwingen“) – ein Browser, der vorher die Warnung übergangen hat, zeigt die Seite sonst weiter als „nicht sicher“. Aufrufen über die IP-Adresse oder den Namen des Containers, wie im Zertifikat eingetragen.
